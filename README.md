# Maza Game

A fun and interactive browser-based game developed using HTML, CSS, and JavaScript. The game provides an engaging user experience with responsive design and smooth gameplay.

##  Features

-  Interactive gameplay
-  Attractive and responsive UI
-  Fast and lightweight
-  Mobile-friendly design
-  Easy to play and restart

##  Technologies Used

- HTML5
- CSS3
- JavaScript

```
Maza-Game/
│── index.html
│── style.css
│── script.js
│── assets/
└── README.md
```

 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/Maza-Game.git
   ```
2. Open the project folder.
3. Run `index.html` in your browser.
